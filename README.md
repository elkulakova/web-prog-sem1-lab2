# To-Do List

Веб-приложение для управления задачами: создание, редактирование, удаление, фильтры, поиск, сортировка, localStorage и drag-and-drop. Стек — HTML, CSS и чистый JavaScript (DOM API).

## Как открыть локально

1. Клонировать репозиторий.
2. Открыть `index.html` в браузере (или через Live Server).

Условие лабораторной: [`TASK.md`](./TASK.md).
